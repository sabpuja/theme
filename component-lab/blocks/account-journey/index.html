SP-ACC · Customer journey system

Account Journey Blocks

A fluid-first system for account access, account creation/welcome, dashboard, orders, order details, thank-you/order confirmation, profile, empty states and support. These blocks are designed as reusable UI contracts so the same visual language can be mapped to Shopify customer-account surfaces and extensions.
