SP-ACC · Customer journey system

Account Journey Blocks

A fluid-first system for account access, account creation/welcome, dashboard, orders, order details, thank-you/order confirmation, profile, empty states and support. These blocks are designed as reusable UI contracts so the same visual language can be mapped to Shopify customer-account surfaces and extensions.

Implementation contract: account blocks are visual and interaction contracts, not a promise that every screen is rendered by the Shopify theme. Current Shopify customer accounts use platform account surfaces and can be extended with customer account UI extensions. The Thank You / Order Status step belongs to Shopify checkout post-purchase surfaces and maps to supported Checkout UI extension targets. We will map each approved block to the correct Shopify surface rather than forcing legacy theme templates where they do not belong.
