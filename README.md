# Sabpuja Component Lab

This directory is the canonical source for the public Sabpuja reusable component preview site.

- Source branch: `staging-2026`
- Public preview: `https://sabpuja.github.io/theme/`
- Shopify production implementation remains in the normal theme directories (`sections/`, `snippets/`, `assets/`, `templates/`, etc.).
- `component-lab/` is development-only and must not be uploaded to Shopify as a theme directory.

Component IDs begin with `SP-COMP-`. The first priority component is `SP-COMP-001 Customer Reviews`.
