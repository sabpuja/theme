Design system

Foundations

Canonical visual and responsive rules for new Sabpuja components: current brand colors, Poppins headings, Inter body copy, proportional spacing, restrained radii, and fluid-first layouts.

Responsive architecture

Fluid first, breakpoint light

Screen width is a continuum, not three device buckets. New Sabpuja components should scale smoothly across the available space instead of jumping between desktop, tablet and mobile presets.

Use fluid values

Use clamp(), min(), max(), intrinsic sizing and percentages for typography, spacing, gutters, media sizes and component dimensions.

Use intrinsic layout

Prefer Grid/Flex with auto-fit, minmax(), wrapping and content-based sizing so layouts adapt naturally without device-specific widths.

Use container context

Reusable sections should respond to the space their own container receives. Prefer container queries over viewport media queries when a true structural switch is required.

Breakpoints are exceptional

Use a query only when layout structure, interaction, art direction or accessibility genuinely must change. Do not add arbitrary breakpoints just to resize fonts, gaps or padding.

Canonical fluid tokens

:root {
  --sp-gutter: clamp(1rem, .6rem + 2vw, 2.5rem);
  --sp-section-y: clamp(2.25rem, 1.25rem + 4vw, 5rem);
  --sp-grid-gap: clamp(.875rem, .65rem + 1vw, 1.5rem);
  --sp-h1: clamp(2rem, 1.4rem + 3vw, 4rem);
  --sp-h2: clamp(1.75rem, 1.3rem + 2vw, 2.75rem);
  --sp-body: clamp(.975rem, .94rem + .15vw, 1.075rem);
}

.sp-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 18rem), 1fr));
  gap: var(--sp-grid-gap);
}

.sp-component {
  container-type: inline-size;
  padding-inline: var(--sp-gutter);
}
Important: the Component Lab’s Desktop / Tablet / Mobile controls and the QA sizes at 1280×720, ~768×1024 and ~390×844 are representative regression test points only. They must not become the design’s CSS breakpoint model.

Typography

Poppins + Inter

Poppins is reserved for headings and high-emphasis display text. Inter handles body copy, labels and interface text. Type sizes should use bounded fluid scales with clamp() rather than breakpoint jumps.

Sabpuja components should feel calm, clear and practical. Body copy remains easy to scan on both large and small screens without decorative type competing with the content.
