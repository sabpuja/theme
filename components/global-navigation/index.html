Production rule: only offer a locale when that Shopify storefront locale is actually published and complete enough to use.

SP-NAV production contract: Header actions must never point to placeholder or broken destinations. Search remains product-scoped; Collections destinations use current Shopify routes; language options appear only for published locales; wishlist and notification controls become interactive only when their workflows exist.
Responsive ruleCollapse before labels or utilities become cramped. Search remains available at every size.
Touch ruleInteractive controls target approximately 44px minimum height/width on narrow layouts.
Sticky ruleScrolled state reduces vertical footprint but preserves logo, search access, account/cart and menu access.
Accessibility ruleAll icon-only controls require accessible names; drawers and menus must manage focus when implemented.
