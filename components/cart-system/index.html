Production contract: Shopify remains the source of truth for line items, variants, quantities, discounts, line totals, subtotal, inventory and checkout eligibility. SP-CART defines the presentation and responsive behavior only. Quantity changes use native/Ajax cart endpoints, status changes are announced with aria-live, unavailable lines identify the exact item, and checkout is blocked only when Shopify or explicit business rules require it. Drawer and full-cart surfaces share the same line-item language.
