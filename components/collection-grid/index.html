SP-COL production contract: collection title, description, product count, filter values, sort options, pagination state and product availability come from Shopify. SP-COL owns layout and interaction hierarchy; every tile renders the canonical SP-PROD product card. Desktop may use a persistent filter rail; tablet/mobile replace it with a drawer. Applied filters must stay visible and removable, and zero-results must always offer recovery.
Shared cardsSP-PROD is the only collection/search product-card visual contract.
Filter sourceUse Shopify-supported collection filters; never invent unavailable facets.
Responsive rule4-up desktop → 3-up tablet → 2-up mobile, with one-column fallback for very narrow containers.
Touch ruleMobile filter, sort, wishlist and product actions remain comfortable touch targets.
