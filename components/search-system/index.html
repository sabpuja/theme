Production contract: predictive search uses Shopify suggestions, debounces requests, cancels stale requests, keeps the query visible, supports Arrow Up/Down, Enter and Escape, and routes to the full search page. Predictive results prioritize products. Full search reuses SP-PROD for products and may list Shopify pages/articles separately. Empty and error states must always preserve a usable recovery path.
Data ownershipShopify provides product title, URL, image, price, availability and full-search result types.
AccessibilityCombobox/listbox semantics, visible keyboard active state, focus return on Escape and approximately 44px touch targets.
PerformanceDebounced requests, aborted stale responses, lazy result images and no duplicate product-card implementation.
Responsive ruleDesktop uses anchored predictive panels; mobile search becomes a focused full-width surface.
